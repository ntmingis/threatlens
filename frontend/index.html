How ThreatLens reaches a status

Every status is computed from findings produced by deterministic engines. No language model takes part in detection.

MALICIOUS
An antivirus signature matched, or a reputation source lists the item as malicious.
SUSPICIOUS
At least one indicator of medium severity or higher. Indicators are reasons to be careful, not proof of malware.
INCONCLUSIVE
A required check could not run or could not cover the whole item, so no statement about it is justified.
CLEAN WITHIN CHECKED SCOPE
Every required check completed and found nothing. This is not a guarantee that the item is safe.

What is not checked

  • Files are never executed; there is no sandbox or behavioural analysis.
  • Submitted URLs are never visited: page content, redirects and certificates are unknown to the tool.
  • Macro code is detected by presence only. Scanned (image-only) PDFs, QR codes and legacy .doc/.xls files are not inspected structurally.
  • Brand look-alike detection covers only the brands in config/brands.json.

Privacy

Uploads are stored under a random name outside the web root and deleted when the scan ends. Only the SHA-256 hash is sent to a reputation provider, and only if you configured an API key. Reports stay in a local database until you delete them.

ThreatLens supports risk assessment. It cannot establish that a file or website is safe.
